# Mindustry Dragon Mod 🐉

**A majestic mod that adds dragons to Mindustry!**

Created by the kind dragon with a saddle (and his rider).

## Features (planned)
- Flying dragon units
- Dragon-themed blocks and turrets
- Fire breath attacks
- Dragon eggs and resources
- Epic dragon bosses

## Installation
1. Download the latest release
2. Place the mod folder or jar into your Mindustry `mods` directory
3. Restart the game and enable the mod

## Structure
```
mindustry-dragon-mod/
├── mod.hjson
├── content/
│   └── units/
├── scripts/
├── sprites/
└── bundles/
```
